

## Job Description

Join an engineering team building AI-assisted capabilities using Python, modern ML techniques, and Large Language Models (LLMs). You will work on data preparation, model integration (via APIs/SDKs), prompt engineering, and evaluation to deliver reliable business outcomes. This role suits a strong problem-solver with solid Python fundamentals and curiosity to learn GenAI / LLM engineering.

### Responsibilities

- Develop Python services, utilities, and notebooks for data processing, feature engineering, and model experimentation.
- Integrate LLMs through provider APIs (e.g., Azure OpenAI / OpenAI / open-source models) following secure and scalable patterns.
- Create and iterate prompts, templates, and guardrails to improve response quality, safety, and consistency.
- Build retrieval-augmented generation (RAG) pipelines: document ingestion, chunking, embeddings, vector search, and grounding.
- Design evaluation approaches for LLM outputs (accuracy, faithfulness, latency, cost) and track improvements.
- Collaborate with QA, product, and business teams to understand requirements and deliver features in Agile sprints.
- Write clean code with unit tests, documentation, and basic CI practices; participate in code reviews.
- Support production issues with structured troubleshooting and root-cause analysis as needed.

## Skills

- Strong Python fundamentals: data structures, OOP basics, modules, exception handling, file I/O.
- Hands-on with common Python libraries: `numpy`, `pandas`; familiarity with `requests` / `fastapi` / `flask` is a plus.
- Basic ML concepts: train/validation, overfitting, metrics; awareness of embeddings and similarity search.
- Understanding of LLM concepts (tokens, context window, prompting) and ability to explain trade-offs clearly.
- SQL fundamentals for querying and data validation (joins, group by, filtering).
- Git basics and a disciplined approach to code quality (tests, formatting, documentation).
- Strong communication and ability to translate problem statements into implementable steps.

## Job Requirements

### Good to Have Skills

- Experience with **LangChain/LlamaIndex** or similar orchestration frameworks.
- Vector databases or search: FAISS, Chroma, Qdrant, Elastic/OpenSearch, Azure AI Search.
- Cloud exposure: Azure (preferred), AWS, or GCP; familiarity with secrets management and IAM concepts.
- MLOps basics: experiment tracking, model/version management, logging/monitoring.
- Knowledge of responsible AI basics: PII handling, bias awareness, safe prompting, content filtering.
